# Cas de test ISTQB

## TC01 - Connexion valide
- Précondition : L'utilisateur possède un compte.
- Étapes : Saisir un email et un mot de passe
  valides, puis cliquer sur Connexion.
- Résultat attendu : L'utilisateur accède
  à son compte.

## TC02 - Mot de passe incorrect
- Étapes : Saisir un email valide et un
  mot de passe incorrect.
- Résultat attendu : Un message d'erreur
  apparaît.

## TC03 - Champs vides
- Étapes : Cliquer sur Connexion sans
  remplir les champs.
- Résultat attendu : Les champs
  obligatoires sont signalés.
