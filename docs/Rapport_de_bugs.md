# Rapport de bugs ISTQB

## BUG-001 - Connexion avec mot de passe incorrect

- Type : Anomalie fonctionnelle (exemple fictif)
- Priorité : Haute
- Statut : À vérifier

## Étapes de reproduction
1. Ouvrir la page de connexion.
2. Saisir un email valide.
3. Saisir un mot de passe incorrect.
4. Cliquer sur Connexion.

## Résultat attendu
Un message d'erreur doit apparaître
et la connexion doit être refusée.

## Résultat observé (scénario fictif)
L'application autorise la connexion
malgré un mot de passe incorrect.

## Conclusion
Cette anomalie doit être vérifiée
et corrigée si elle est reproduite.
